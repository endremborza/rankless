How sessions get classified

A session is a stream of requests from the same IP+UA, split when idle for >30 minutes. Each session is bucketed into one of the five classes below using the rules on this page. Hard rules fire deterministically; soft rules contribute to a score that is thresholded at ±3.

Classes

  • bot_known
  • bot_likely
  • unknown
  • human_likely
  • human_known

Hard rules — bot side

Any of these → bot_known. Rates over 185,353 sessions.

  • empty_ua — User-Agent header missing or empty. 0.01%
  • bot_ua — User-Agent matches a known bot/crawler/script family. 19.20%
  • robots_or_sitemap — Hit one of the bot-only routes: ['/robots.txt', '/sitemap*.xml']. 0.12%
  • all_HEAD — Every request in the session uses the HEAD method. 0.01%

Hard rules — human side

Any of these → human_known, unless a bot hard rule already fired (bots win).

Soft rules

Applied only when no hard rule fired. Scores are summed; the session lands as human_likely at score ≥ 3, bot_likely at score ≤ 0, otherwise unknown.
